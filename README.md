# 378Q

四人对家组队牌类游戏的单机第一阶段实现，项目独立位于 `E:\q873`，不会修改原三国杀项目。

## 启动

```bash
npm install
npm run dev
```

浏览器打开 `http://localhost:5173/`。P0 为真人，P1/P2/P3 为贪心 AI。

## 部署到 GitHub Pages（可在线游玩）

本项目为纯前端静态应用,可直接部署到 GitHub Pages 在线游玩:

1. 在 GitHub 新建仓库(示例名 `378q`,公开/私有均可,Pages 需公开或 Pro);
2. 推送代码:

   ```bash
   cd E:\q873
   git init
   git add .
   git commit -m "378Q 扑克牌游戏"
   git branch -M main
   git remote add origin https://github.com/<你的用户名>/378q.git
   git push -u origin main
   ```

3. 仓库 **Settings → Pages → Source** 选择 **GitHub Actions**;
4. 推送后 Actions 自动构建部署,约 1 分钟后访问:
   `https://<你的用户名>.github.io/378q/`

工作流位于 `.github/workflows/deploy.yml`,每次 push 到 main 自动重新部署。构建产物为相对路径(`base: "./"`),放在任意子路径或本地直接打开 `dist/index.html` 也能运行。

## 验证

```bash
npm run test
npm run build
```

当前包含 108 张双副牌、第一局分牌与 500 分守恒、统一点数顺序、六种牌型、压牌、队友可管牌、PASS 输分、连续三次 PASS、庄家轮换、后续 80 张发牌、AI 候选生成、完整牌型评估和自动对战回归测试。积分允许低于 0，任意队伍积分 `< -200` 时结束大局。

牌桌视觉:手牌、桌面出牌区、亮牌区均使用真实扑克牌面渲染——基于开源 [card-t](https://github.com/girvan/playingcardts) Web Component(52 张 SVG 标准法式牌面,含 JQK 人物图与立体阴影,Unlicense 公有领域授权,可自由商用;零依赖、零外部图片请求,库文件本地位于 `public/element.card-t.full.js`);大小王无对应牌面,以文字样式渲染。

玩家形象:四个座位各有固定的动漫风头像(本地 `public/avatars/p0~p3.png`),昵称从昵称池随机生成(均不超过 4 个汉字),点"新局"重新随机;小局(及大局)结束后,记分栏下方出现结算面板,显示红蓝两队本局积分变化(+赢/-输)及"起始分 → 结算分",与 3 秒亮牌阶段同步出现。

出牌播报使用浏览器内置中文语音，所有点数以汉字播报（二/三/四/六/七/八/九），单 A/J 播报为“尖/勾”，对子为“对 X”，氢弹为“X 氢”，炸弹为“X 炸”，Q873 为“三七八夺”，同花 Q873 为“顺三七八夺”（避免 TTS 把"378"读成"三百七十八"）。压住对手时会随机喊出“大你/压上/吃你了”等口播，PASS 时会说“不要/要不起/过”；右上角提供语音开关（状态记忆在 localStorage）。浏览器首次需要用户点击后才允许自动语音。

手气卡:仅玩家可用(AI 不使用),每小局 3 次,首局不可用,且本小局还没人出牌/过牌时才能使用。使用后全桌手牌收回重洗、按各人原手牌数重发(庄家、回合、得分不变),并立即重置 3 秒准备倒计时,行动区会出现"🎴 手气卡 ×N"按钮。

提示:行动区"💡 提示"按钮一键帮玩家选好当前最优出牌组合(压牌时优先用刚好能压住的最小组合,并遵循 AI 同款的牌型结构保护与炸弹>378Q>氢弹分级策略),自动高亮对应手牌,点"出牌"即打出;没有能压住的牌时会提示建议过牌。

节奏控制:每小局开始有 3 秒准备倒计时(3→2→1→GO),倒计时期间 AI 与玩家都不能出牌,玩家可利用这个窗口使用手气卡;倒计时结束后庄家开始出牌。每小局结束后进入 3 秒亮牌阶段——所有未出完牌的玩家(含 AI)手牌在座位下方明示,期间"下一小局"按钮禁用,亮牌结束后才可继续。

AI 评估会保护牌型结构:手上 3/7/8/Q 齐全时不会拆 Q873 去压小牌,凑齐的氢弹（四张同点）与炸弹（三带二）同样受保护；领牌与跟牌均生效。用大招接牌遵循优先级**炸弹 > 普通 378Q > 氢弹 > 顺 378Q**（浪费惩罚 120/250/500/800 分级）:开局阶段（手牌 ≥14 张）惩罚 ×3——第一轮宁可 PASS 期待队友接牌；收尾阶段（手牌 ≤6 张）惩罚 ×0.6——该出手就出手；队友尚未 PASS 时额外 +300（队友可能还能接）；对家不管后己方压牌 +600；敌方已出炸弹级牌时大招跟上不算浪费；敌方剩牌 ≤2 张的紧急时刻豁免一切惩罚全力压制。

视觉与动效：开局/下一局手牌逐张飞入（发牌动画），桌面出牌区逐张翻入；打出炸弹触发橙色爆炸冲击波 + 桌面震动，氢弹为三重青色冲击波 + 强震，378Q（含同花“顺 378 夺”）触发金色光环特效。
